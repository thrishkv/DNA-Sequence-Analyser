# DNA Sequence Analyzer

## Overview

The DNA Sequence Analyzer is a Python project designed to analyze DNA sequences using fundamental bioinformatics techniques.

## Project Goals

* Validate DNA sequences.
* Calculate nucleotide composition and GC content.
* Transcribe DNA into RNA.
* Translate nucleotide sequences into amino acid sequences.
* Test the analyzer using valid and invalid inputs.
